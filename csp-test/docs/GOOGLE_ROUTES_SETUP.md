# Google Routes API für v0.8

1. Google Cloud Console öffnen.
2. `APIs & Dienste → Bibliothek` öffnen.
3. **Routes API** suchen und aktivieren.
4. Unter `APIs & Dienste → Anmeldedaten → API-Key` bei den API-Einschränkungen zusätzlich **Routes API** erlauben.
5. Die HTTP-Referrer-Einschränkung auf `https://tbischoff.github.io/Budapest_10_2026/*` beibehalten.
6. GitHub Pages öffnen, `Cmd + Shift + R`, einen Tag mit mindestens zwei Orten wählen und `🚶 Fußroute anzeigen` testen.

Hinweis: Bis zu 25 Zwischenstopps werden unterstützt. Ab 11 Zwischenstopps gelten höhere Abrechnungsraten.
