# v0.8.1 – Routes Hotfix

## Behoben

Die Routes Library akzeptiert `units: "METRIC"` nicht als String.
Das Feld wurde entfernt.

Für die Anwendung ist keine explizite UnitSystem-Einstellung nötig, da
`distanceMeters` ohnehin in Metern zurückgegeben und von der Anwendung
selbst formatiert wird.

## Abnahmetest

1. `assets/js/app.js` ersetzen.
2. GitHub Pages mit `Cmd + Shift + R` neu laden.
3. Einen Tag mit mindestens zwei Orten auswählen.
4. `🚶 Fußroute anzeigen` klicken.
5. Der Fehler `Unknown UnitSystem: METRIC` darf nicht mehr erscheinen.
6. Prüfen, ob die echte Fußroute dargestellt wird.
7. Distanz und Gehzeit prüfen.
8. Route aus-/einblenden.
9. Tagesreihenfolge ändern und Route erneut berechnen.
10. Browser-Konsole auf neue Fehler prüfen.

## Abnahme

Wenn alles passt: `v0.8.1 abgenommen`.
