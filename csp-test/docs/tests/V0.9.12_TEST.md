# v0.9.12 – Trefferkarten direkt unter der Suche

## Abnahmetest

1. `Orte` öffnen.
2. Oben muss das Suchfeld erscheinen.
3. Suchtext eingeben.
4. Suchvorschläge müssen direkt unter dem Suchfeld erscheinen.
5. Direkt darunter müssen `Orte`, Trefferzahl und die vollständigen Trefferkarten erscheinen.
6. Prüfen, dass Karteninhalt vollständig sichtbar ist:
   - Name
   - Kategorie
   - Entfernung
   - Reisetag
   - Uhrzeit
   - Beschreibung/Notiz
7. Erst danach dürfen Standort, Kategorien und Zusatzfilter folgen.
8. Suche leeren → vollständige Ortsliste erscheint weiterhin direkt unter der Suche.
9. Android und Desktop testen.
10. Browser-Konsole auf Fehler prüfen.

## Abnahme

Wenn alles passt: `v0.9.12 abgenommen`.
