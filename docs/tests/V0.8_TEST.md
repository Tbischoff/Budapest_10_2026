# v0.8 – Echte Tagesroute

## Abnahmetest

### Voraussetzung

Routes API in Google Cloud aktivieren und beim verwendeten API-Key freigeben.

### Funktionstest

1. GitHub Pages mit `Cmd + Shift + R` neu laden.
2. Browser-Konsole öffnen und auf Fehler prüfen.
3. Einen Reisetag mit mindestens zwei Orten auswählen.
4. `🚶 Fußroute anzeigen` anklicken.
5. Prüfen, ob die Route entlang tatsächlicher Straßen und Fußwege verläuft.
6. Prüfen, ob Gesamtdistanz angezeigt wird.
7. Prüfen, ob geschätzte Gehzeit angezeigt wird.
8. Route ausblenden und erneut anzeigen.
9. Reihenfolge eines Ortes mit ↑ / ↓ ändern.
10. Route erneut berechnen und prüfen, ob die neue Reihenfolge berücksichtigt wird.
11. Einen Ort zu diesem Tag hinzufügen und Route neu berechnen.
12. Einen Ort aus diesem Tag entfernen und Route neu berechnen.
13. `Google Maps` öffnen und Reihenfolge vergleichen.
14. Tag wechseln: die vorherige Route muss verschwinden.
15. Tag mit weniger als zwei Orten prüfen: Route-Button deaktiviert.
16. Standort, Entfernung und Nähe-Sortierung gegenprüfen.
17. Uhrzeiten/Zeitfenster gegenprüfen.
18. Eigenen Ort hinzufügen und löschen.
19. Test auf Smartphone durchführen.

### Fehlerfall Routes API

Routes API testweise noch nicht aktiviert oder nicht für den Key freigegeben:

- Anwendung soll nicht abstürzen.
- Es soll eine verständliche Meldung erscheinen, dass die Routes API geprüft werden muss.

## Abnahme

Wenn alles passt: `v0.8 abgenommen`.

Danach: `v0.9 – Mobile UI / Bedienoptimierung`.
