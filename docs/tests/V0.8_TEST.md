# v0.8 – Abnahme

1. Routes API aktivieren und beim Key freigeben.
2. `Cmd + Shift + R`.
3. Tag mit mindestens zwei Orten auswählen.
4. `🚶 Fußroute anzeigen` anklicken.
5. Prüfen, ob die Linie realen Straßen/Fußwegen folgt.
6. Distanz und Gehzeit prüfen.
7. Route aus-/einblenden.
8. Reihenfolge ändern und Route neu berechnen.
9. Google-Maps-Button testen.
10. Tag wechseln; alte Route muss verschwinden.
11. Standort, Entfernung, Uhrzeiten, Ort hinzufügen und Filter gegenprüfen.
12. Smartphone-Test.

Wenn alles passt: `v0.8 abgenommen`.
