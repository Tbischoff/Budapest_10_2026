## Abnahmetest

1. Die neue Ordnerstruktur vollständig ins Repository übernehmen.
2. Alte Root-Dateien `app.js`, `style.css`, `places.js`, `places.json` und `favicon.svg`
   erst löschen, wenn die neue Version deployed ist.
3. GitHub Pages neu laden.
4. `Cmd + Shift + R`.
5. Prüfen, ob Styling geladen wird.
6. Prüfen, ob alle Orte geladen werden.
7. Marker öffnen.
8. Tagesplanung prüfen.
9. Reihenfolge prüfen.
10. Uhrzeiten prüfen.
11. Tagesroute prüfen.
12. Standort und Entfernung prüfen.
13. `Ort hinzufügen` prüfen.
14. Browser-Konsole auf 404-/Pfadfehler prüfen.

## Abnahme

Wenn alles passt: `v0.7.1 abgenommen`.

Danach kann v0.8 auf dieser Struktur aufbauen.
