# v0.9.11 – Ortsliste unter der Suche

## Abnahmetest

1. `Orte` öffnen.
2. Direkt oben muss das Suchfeld erscheinen.
3. Suchbegriff eingeben.
4. Suchvorschläge müssen unmittelbar unter dem Suchfeld erscheinen.
5. Die gefilterte Ortsliste muss direkt darunter erscheinen.
6. Trefferzahl prüfen.
7. Einen Suchvorschlag antippen → Marker + Infofenster prüfen.
8. Einen Eintrag aus der Ortsliste antippen → bisheriges Verhalten prüfen.
9. Suche leeren → vollständige Ortsliste erscheint wieder.
10. Kategorien und weitere Filter müssen weiterhin vorhanden und bedienbar sein.
11. Android und Desktop testen.
12. Browser-Konsole auf Fehler prüfen.

## Abnahme

Wenn alles passt: `v0.9.11 abgenommen`.
