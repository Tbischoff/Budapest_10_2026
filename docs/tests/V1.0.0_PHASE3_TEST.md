# V1.0.0 – Phase 3 / Build 1

## Vorbereitung
`docs/V1.0.0_PHASE3_REALTIME.sql` einmal im Supabase SQL Editor ausführen.

## Live-Test
1. Mac und Android gleichzeitig öffnen und mit den zwei Benutzern anmelden.
2. Beide Apps müssen nach dem Laden `Live-Synchronisation aktiv` melden.
3. Auf Gerät A einen Ort einem Tag zuweisen.
4. Gerät B NICHT neu laden: die Änderung soll automatisch erscheinen.
5. Reihenfolge, besucht sowie Start-/Endzeit ebenfalls testen.
6. Änderung auf Gerät B durchführen und automatische Aktualisierung auf A prüfen.
7. Sicherstellen, dass keine Endlosschleife von Statusmeldungen/Updates entsteht.
8. Browser-Konsole auf Fehler prüfen.
