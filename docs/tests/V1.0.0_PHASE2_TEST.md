# V1.0.0 – Phase 2: Planung synchronisieren

## Vor dem Deployment
Im Supabase SQL Editor zuerst `docs/V1.0.0_PHASE2_DATABASE.sql` ausführen.

## Zwei-Geräte-Test
1. Gerät A und Gerät B mit den zwei vorhandenen Benutzern anmelden.
2. Auf A einen Ort einem Reisetag zuweisen.
3. Kurz auf die Meldung `Planung synchronisiert` warten.
4. B neu laden: dieselbe Tageszuordnung muss erscheinen.
5. Auf A die Reihenfolge ändern; B neu laden und prüfen.
6. Auf A einen Ort als besucht markieren; B neu laden und prüfen.
7. Start- und Endzeit setzen; B neu laden und prüfen.
8. Tageszuordnung wieder entfernen; B neu laden und prüfen.
9. Auf B eine Änderung durchführen; A neu laden und Gegenrichtung prüfen.
10. Browser-Konsole auf Fehler prüfen.

Phase 2 synchronisiert den Planungszustand über `trip_places`.
