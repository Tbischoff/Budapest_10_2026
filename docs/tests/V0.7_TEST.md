# v0.7 – Tagesroute

## Neu

Für jeden Reisetag kann jetzt eine Route anhand der geplanten Reihenfolge dargestellt werden.

### Route auf der Budapest Map

- konkreten Reisetag auswählen
- mindestens zwei Orte müssen diesem Tag zugewiesen sein
- `🗺️ Route anzeigen` verbindet die Orte in der geplanten Reihenfolge
- die Karte zoomt automatisch auf die Tagesroute
- die Verbindung ist bewusst nur eine Luftlinien-/Planungsdarstellung
- `Route ausblenden` entfernt die Linie wieder

### Google Maps

Über `Google Maps` wird die aktuelle Tagesreihenfolge an Google Maps übergeben.

- erster Ort = Start
- letzter Ort = Ziel
- alle Orte dazwischen = Zwischenstopps
- Reisemodus = zu Fuß

Google Maps berechnet dort die tatsächliche Wegführung.

## Verhalten

- Ändert sich die Reihenfolge eines Tages, wird eine aktive Route neu gezeichnet.
- Wird ein Ort dem Tag hinzugefügt oder entfernt, wird die aktive Route aktualisiert.
- Beim Wechsel auf einen anderen Tag bzw. `Alle` oder `Noch offen` wird die bisherige Route ausgeblendet.
- Tagesreihenfolge bleibt weiterhin die maßgebliche Reihenfolge.
- Uhrzeiten aus v0.6 verändern die Reihenfolge nicht automatisch.

## Abnahmetest

1. Einen Tag mit mindestens zwei Orten auswählen.
2. Prüfen, ob `Route anzeigen` aktiv wird.
3. `Route anzeigen` anklicken.
4. Prüfen, ob alle Tagesorte in der geplanten Reihenfolge verbunden werden.
5. Prüfen, ob die Karte automatisch auf die Route zoomt.
6. `Route ausblenden` testen.
7. Route erneut anzeigen und mit ↑ / ↓ die Reihenfolge verändern.
8. Prüfen, ob die Linie automatisch aktualisiert wird.
9. Einen weiteren Ort dem aktiven Tag hinzufügen.
10. Prüfen, ob die Route aktualisiert wird.
11. Einen Ort aus dem Tag entfernen.
12. Prüfen, ob die Route aktualisiert wird.
13. Auf einen anderen Reisetag wechseln und prüfen, ob die bisherige Route verschwindet.
14. Einen Tag mit nur einem Ort auswählen: Route-Button muss deaktiviert sein.
15. `Google Maps` öffnen.
16. Prüfen, ob Start, Ziel und Zwischenstopps in der geplanten Reihenfolge übernommen werden.
17. Standort, Entfernung und Nähe-Sortierung gegenprüfen.
18. Uhrzeiten/Zeitfenster gegenprüfen.
19. `Ort hinzufügen`, Kategorien, Suche und Besucht-Status testen.
20. Smartphone-Test durchführen.
