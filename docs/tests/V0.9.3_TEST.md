# v0.9.3 – Mobile Auto-Close

## Abnahmetest

1. Auf Android `Plan` öffnen.
2. Einen konkreten Tag, z. B. `Sa 03.10.`, auswählen.
3. Bottom Sheet muss sich automatisch schließen.
4. Karte muss direkt sichtbar sein.
5. `Plan` erneut öffnen: ausgewählter Tag muss weiterhin aktiv sein.
6. `Alle` auswählen: Sheet bleibt geöffnet.
7. `Noch offen` auswählen: Sheet bleibt geöffnet.
8. `Orte` öffnen und Kategorien ändern: Sheet bleibt geöffnet.
9. Desktop/Mac gegenprüfen: Verhalten der Sidebar bleibt unverändert.

## Abnahme

Wenn alles passt: `v0.9.3 abgenommen`.
