# v0.9.5 – Mobile UX Refinement

## Abnahmetest Android

### Standort

1. `Orte` öffnen.
2. `Mein Standort` / `Standort aktualisieren` antippen.
3. Nach erfolgreicher Standortermittlung muss das Sheet automatisch schließen.
4. Karte und Standortmarker müssen sichtbar sein.

### Plan / Orte als Toggle

5. `Plan` antippen → Sheet öffnet sich.
6. `Plan` erneut antippen → Sheet schließt sich.
7. `Orte` antippen → Sheet öffnet sich.
8. `Orte` erneut antippen → Sheet schließt sich.
9. Zwischen `Plan` und `Orte` wechseln.

### Marker-Infofenster

10. Marker öffnen.
11. Auf eine freie Stelle der Karte tippen → Infofenster muss schließen.
12. Marker öffnen und danach `Plan` antippen → Infofenster muss schließen.
13. Marker öffnen und danach `Orte` antippen → Infofenster muss schließen.
14. Marker A öffnen, danach Marker B → nur Marker B darf offen sein.

### Regression

15. Tagesauswahl → Auto-Close testen.
16. Fußroute anzeigen / ausblenden → Auto-Close testen.
17. Kategorien und Suche testen.
18. Desktop/Mac gegenprüfen.
19. Browser-Konsole auf neue Fehler prüfen.

## Abnahme

Wenn alles passt: `v0.9.5 abgenommen`.
