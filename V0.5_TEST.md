# v0.5 – Reihenfolge innerhalb eines Tages

## Neu

- Jeder einem Tag zugeordnete Ort erhält eine Reihenfolge.
- Beim Filtern auf einen konkreten Reisetag werden die Orte standardmäßig in dieser Reihenfolge angezeigt.
- Über `↑` und `↓` kann die Reihenfolge direkt in der Ortsliste geändert werden.
- Neu einem Tag zugeordnete Orte werden automatisch hinten angefügt.
- Wird ein Ort auf einen anderen Tag verschoben oder aus der Planung entfernt, werden die Nummern automatisch neu sortiert.
- Bestehende Tagesplanungen aus v0.4 werden beim ersten Laden automatisch durchnummeriert.
- `Nähe sortieren` bleibt als bewusste alternative Sortierung erhalten.

## Bedienung

1. In der Tagesplanung z. B. `Sa 03.10.` auswählen.
2. Nur für diesen Tag geplante Orte werden angezeigt.
3. Jeder Ort bekommt eine Nummer und Pfeile `↑` / `↓`.
4. Mit den Pfeilen die gewünschte Reihenfolge festlegen.
5. Die Reihenfolge wird im `localStorage` gespeichert.

## Abnahmetest

1. Einen konkreten Tag auswählen.
2. Prüfen, ob alle Orte dieses Tages eine fortlaufende Nummer haben.
3. Einen Ort mit `↑` verschieben.
4. Einen Ort mit `↓` verschieben.
5. Seite mit Cmd + Shift + R neu laden und prüfen, ob die Reihenfolge erhalten bleibt.
6. Einen neuen Ort diesem Tag zuordnen und prüfen, ob er am Ende erscheint.
7. Einen Ort auf einen anderen Tag verschieben und prüfen, ob beide Tage anschließend sauber durchnummeriert sind.
8. Einen Ort wieder auf `Tag auswählen` setzen und prüfen, ob die Lücke geschlossen wird.
9. `Nähe sortieren` aktivieren und prüfen, ob diese Sortierung weiterhin funktioniert.
10. Nähe-Sortierung wieder deaktivieren: Tagesreihenfolge muss wieder erscheinen.
11. Standort, Kategorien, Suche, Local-Tipps, `Ort hinzufügen` und Besucht-Status kurz gegenprüfen.
12. Test auf Smartphone durchführen.

## Abnahme

Wenn alles passt: `v0.5 abgenommen`.

Danach ist als technische Zwischenstufe `v0.5.1` die Migration von `google.maps.Marker`
auf `AdvancedMarkerElement` vorgesehen.
