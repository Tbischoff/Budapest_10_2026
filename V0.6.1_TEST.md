# v0.6.1 – Google Maps API Cleanup

## Zweck

Technische Bereinigung der Google-Maps-Advanced-Marker-Integration.
Keine fachlichen Änderungen gegenüber v0.6.

## Änderungen

- `PinElement.glyph` durch `glyphText` ersetzt
- `pin.element` entfernt
- `PinElement` wird direkt an `AdvancedMarkerElement` angehängt
- Marker-Klicks verwenden `addEventListener("gmp-click", ...)`
- Marker erhalten `gmpClickable: true`
- Standortmarker ebenfalls auf die aktuelle PinElement-Nutzung angepasst
- `favicon.svg` ergänzt
- Favicon in `index.html` eingebunden

## Geänderte Dateien

- `app.js`
- `index.html`

## Neue Datei

- `favicon.svg`

## Unverändert

- `style.css`
- `places.js`
